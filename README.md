16ビット浮動小数点数 シミュレータ（高校情報Ⅰ対応）

高校情報Ⅰの必修単元「数値の表現（コンピュータにおける数値表現と誤差）」を直感的に学習できるインタラクティブなWebアプリケーションです。

16ビット（IEEE 754 半精度浮動小数点数格式）の構造（符号・指数部・仮数部）を、ビットを操作しながらリアルタイムに計算プロセスと誤差の発生を視覚的に理解できます。

🌟 主な機能

1. ビット操作 & 解析（ビット実験室）

インタラクティブな16ビット操作: Bit 15（符号）、Bit 14〜10（指数部）、Bit 9〜0（仮数部）のスイッチをクリックして自由に値を切り替え。

リアルタイム数式展開:

符号判定: $(-1)^S$

バイアス計算: $2^{(E - 15)}$

隠しビット（Hidden Bit）の復元: $(1 + f)$

ワンタップ・プリセット: 1.0, -2.5, 65504 (最大値), 0.1 (丸め誤差), +無限大, NaN などの代表的な数値を瞬時にセット。

2. 10進数変換 & 丸め誤差シミュレータ

双方向シミュレーション: 任意の10進数を入力（またはスライダー操作）すると、16ビットに正規化・丸められる手順（ステップ1〜5）を順を追って解説。

丸め誤差の可視化: 0.1 や 0.00005 など、コンピュータ内で正確に表現できず近似値（丸め誤差）が発生する現象を定量的に差分表示。

3. 確認クイズ（定着度チェック）

高校情報Ⅰの定期テストや共通テストで出題されやすい選択式問題（5問）を収録。

100点満点でスコアを表示し、詳細な解説で理解を深めることが可能。

4. 基礎解説 & 用語集

教科書に準拠した基本構造の解説。

浮動小数点数に特有の重要用語（丸め誤差、桁落ち、情報落ち、オーバーフロー、隠しビット、バイアス表現）をカード形式で整理。

基本計算式（正規化数の場合）

$$\text{Value} = (-1)^{\text{Sign}} \times \left( 1 + \frac{\text{Mantissa}}{1024} \right) \times 2^{(\text{Exponent} - 15)}$$

🎓 授業での活用例（先生・指導者向け）

導入・デモンストレーション (10分)

「なぜ 0.1 + 0.2 が 0.30000000000000004 になるのか？」といった問いかけから、アプリのプリセット 0.1 (丸め誤差あり) を提示。

個人・グループワーク (20分)

「1.0 のビット列はどうなるか？」「-2.5 を作ってみよう」などの課題を提示し、生徒自身にビットを動かして計算式を確かめさせる。

誤差の実験 (10分)

「10進数変換」タブでスライダーを動かし、誤差ゼロで表せる数（$0.5$, $0.25$, $6.25$ など）と誤差が出る数（$0.1$, $0.3$ など）の違いを観察・考察。

まとめ・小テスト (10分)

「確認クイズ」で授業の定着度を確認。

💻 技術構成 / 動作環境

単一HTML構成 (Single File): サーバーやビルド環境不要で、ブラウザ（Chrome, Edge, Safari等）で index.html を開くだけで即座に動作します。

Tailwind CSS (CDN): モダンで直感的なダークモードUI。

FontAwesome (CDN): アイコン装飾。

Vanilla JavaScript: 外部ライブラリ依存なしの軽量・高速動作。
